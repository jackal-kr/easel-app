# Mutants for tools/mutate.sh: one deliberate bug each, for the rules that guard against losing the user's work.
# Block format (see docs/engineering.md, "Mutation tool"):
#   === REQ-NNNN-xx short name of the bug
#   file: path of the source file, from the project root
#   test: the meson test names (space separated) that must fail, for example core-resize or ui-0005
#   --- find
#   the exact text to find (must occur once; may span lines)
#   --- replace
#   the text that takes its place
# The text of a mutant has no blank line (a blank line ends the block). A mutant is KILLED when one of its tests fails,
# and SURVIVES when they all pass.
