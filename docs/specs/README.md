# Specs

One folder per feature: `NNNN-slug/` with `spec.md` (what/why), `plan.md` (how), `tasks.md` (slices).
Templates in `_templates/`. Spec status: `draft` -> `clarified` -> `accepted` -> `implemented`.
IDs: `REQ-NNNN-xx` requirements, `AS-n` scenarios (numbered within the spec), `T001` tasks.
Lint: `tools/check-trace.sh`.
