# 0022 UI languages

Status: draft
Depends on: 0001 (settings file, the 0001 strings), Preferences (the language picker)

## Why
Easel's users read Czech, German, Spanish, French, Hungarian, Italian, Polish, Portuguese, Romanian, Russian and Ukrainian as well
as English. The interface speaks their language, and English stays the default for everyone else.

## Requirements
- REQ-0022-01 The app shall offer its interface in twelve languages, listed by code in alphabetical order: cs Czech, de German,
  en English, es Spanish, fr French, hu Hungarian, it Italian, pl Polish, pt Portuguese (as in Brazil, pt_BR), ro Romanian,
  ru Russian, uk Ukrainian (locale uk_UA; JOD, 2026-10-27). Every string the app shows is translatable and is not built by
  concatenation (design.md): window titles, menus, tooltips, hints, the status bar, dialogs and accessible names, including the 0001
  strings. GTK's own strings (the file and color choosers) follow GTK's translation of the same language.
- REQ-0022-02 English shall be the default (JOD, 2026-10-27): the source strings are English, English has no translation of its
  own and is never incomplete. The app shall show English (a) when the setting is `auto` and the system's language is not one of the
  twelve, and (b) for a single string the chosen language lacks, that string only.
- REQ-0022-03 The system's language shall be the first of the user's preferred languages (the desktop's list) that is one of the
  twelve, matched by its language part: de_AT is German, pt_PT is Portuguese (the pt_BR translation), en_GB is English.
- REQ-0022-04 Preferences shall have a Language list. Its first entry is "System default", which follows the system's language
  (English if that is not one of the twelve). After it come the twelve languages by their own names, which are not translated:
  Čeština, Deutsch, English, Español, Français, Magyar, Italiano, Polski, Português, Română, Русский, Українська, sorted with the
  collation of the interface's current language (JOD, 2026-10-27). The settings file keeps the choice as `[interface]`
  `language=`: `auto` for System default, otherwise the code. A new settings file has `language=auto`. A missing or invalid value
  is `auto` (REQ-0001-05), and the code is case-insensitive (REQ-0001-40).
- REQ-0022-05 A change of language shall take effect as the Open questions settle.
- REQ-0022-06 A message with a count shall take the interface language's plural form for that count. English, French and
  Hungarian have two forms; in English and Hungarian only 1 is singular, in French 0 and 1 are. Czech, Polish, Romanian, Russian
  and Ukrainian have three forms, by each language's standard rule (AS-5).
- REQ-0022-07 A language is complete when every string is translated and a native reader has checked it; the table under Edge
  cases records the reader and the date for each language (JOD, 2026-10-27). An incomplete language is still offered, marked
  incomplete in the picker (how: Open questions), and shows English for each string it lacks (REQ-0022-02).
- REQ-0022-08 0022 has no right-to-left language, so the layout is never mirrored (JOD, 2026-10-27).

## Scenarios
- AS-1 (REQ-0022-01, REQ-0022-03) Given `language=auto`, When the app starts with the system language de_DE, Then the menus are in German; with uk_UA, in Ukrainian; with pt_PT, in Portuguese (pt_BR); with de_AT, in German; with the preferred list "ja, pl", in Polish | Verified by: automated (ui)
- AS-2 (REQ-0022-02) Given `language=auto`, When the app starts with the system language ja_JP, Then everything is in English; with C, the same | Verified by: automated (ui)
- AS-3 (REQ-0022-02, REQ-0022-07) Given `language=pl` and a Polish translation that lacks one menu item, When the app starts, Then that item is in English and the others are in Polish | Verified by: automated (ui, a test translation)
- AS-4 (REQ-0022-04) Given the English interface, When the Language list opens, Then it reads System default, Čeština, Deutsch, English, Español, Français, Italiano, Magyar, Polski, Português, Română, Русский, Українська; When Polski is chosen, Then the settings file has `language=pl`; When System default is chosen, Then it has `language=auto`; Given `language=xx`, `language=` or no key, Then System default is chosen; Given `language=PL`, Then Polski | Verified by: automated (ui) + manual M2 (the order under other collations)
- AS-5 (REQ-0022-06) Given each language, When the message "N pixels" (the brush presets' names) is formed for 0, 1, 2, 5, 12 and 22, Then it takes these forms (computed from each language's standard plural rule): cs 0 other, 1 one, 2 few, 5 other, 12 other, 22 other; fr 0 one, 1 one, 2 other, 5 other, 12 other, 22 other; hu 0 other, 1 one, 2 other, 5 other, 12 other, 22 other; pl 0 many, 1 one, 2 few, 5 many, 12 many, 22 few; ro 0 few, 1 one, 2 few, 5 few, 12 few, 22 other; ru 0 many, 1 one, 2 few, 5 many, 12 many, 22 few; uk 0 many, 1 one, 2 few, 5 many, 12 many, 22 few; en 0 other, 1 one, 2 other, 5 other, 12 other, 22 other | Verified by: automated (the build's translations)
- AS-6 (REQ-0022-07) Given a translation with an untranslated string, Then the build marks that language incomplete and the picker shows the mark; Given every string translated and the reader recorded, Then no mark | Verified by: automated (build) + manual M2 (each native reader)
- AS-7 (REQ-0022-08) Given each of the twelve languages, Then the toolbox is at the left and the palette's colors run left to right | Verified by: manual M1

- Sorting: the English order is in AS-4; the order under other collations is M2's.
