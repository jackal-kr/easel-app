# XP hidden behaviors to keep (seed list, verify and extend while writing specs)

- Shift-drag smears a selection; Shift-click stamps it.
- Numpad +/- resizes the brush.
- Ctrl+G toggles grid at 4x zoom and above.
- Second mouse button cancels a stroke in progress.
- Pasting an image larger than the canvas asks before changing anything (this app's choices are in `new-behaviors.md`).
- Rounded-rectangle corner radius is capped at 8.
- Airbrush sprays on a 5 ms timer.
- Right button draws with the background color; on a selection or text box it opens a context menu instead.
