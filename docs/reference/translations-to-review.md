# Translations to review

For JOD. Only what is new or changed since the last commit (987542b, 2026-11-09): the menu mnemonics moved so that no two labels of
one menu page share a letter (0035 Check F1, kept by `/0023-lang/as14_menu_mnemonics_differ`), and the strings 0035 adds (the classical version's dialog: its heading, its line and Tolerance; the model version's four strings removed). The
underscore marks the letter. A word is wrong, or a letter hard to type on your keyboard: say which, and the letter is moved again
(the test says whether the new one is free).
